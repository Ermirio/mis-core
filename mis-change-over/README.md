# MIS Change Over

Repository for the Automatic Changeover (Troca Automática) module of the Manufacture Integrated System (MIS).

## Description
This module handles the synchronization of SKUs and the automatic configuration of line equipment based on the selected SKU.

## Features
- SKU Synchronization with ERP/Database.
- Automatic parameter configuration for connected equipment.
- Exchange history and logs.
- Real-time feedback and progress tracking.

## Getting Started
1. Clone the repository.
2. Install dependencies.
3. Configure environment variables.
