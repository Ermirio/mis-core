# Relatório de Novas Funcionalidades: Controle Preditivo e Treinamento Automatizado

**Autor**: Manus AI
**Data**: 31 de janeiro de 2026

## 1. Introdução

Este documento detalha as novas funcionalidades implementadas no projeto **MIS-AI**, com foco em transformar o sistema de um preditor passivo para um **controlador preditivo ativo**. As melhorias visam automatizar o treinamento de modelos de Machine Learning e introduzir um sistema de recomendação de ajustes em tempo real para otimização de processos industriais.

As principais funcionalidades adicionadas são:

- **Treinamento Automatizado**: Através de **Variáveis de Referência**, o sistema agora captura automaticamente os valores medidos do processo, eliminando a necessidade de inserção manual e permitindo o retreinamento contínuo dos modelos.
- **Controle Preditivo**: Com a introdução de **Variáveis de Controle**, o sistema passa a recomendar ajustes automáticos no processo com base nas predições do modelo, visando corrigir desvios e otimizar o resultado final.
- **Lógica de Ajuste Proporcional**: O controle preditivo é parametrizável, permitindo configurar a **direção da lógica** (direta ou reversa) e a **intensidade do ajuste** (fator de relação), tornando-o flexível para diferentes cenários industriais.

## 2. Arquitetura e Implementação Técnica

Para suportar as novas funcionalidades, foram realizadas alterações significativas na arquitetura do backend, incluindo a criação de novos módulos e a extensão dos modelos de dados existentes.

### 2.2. Módulos de Lógica de Negócio

Dois novos módulos Python foram criados no backend para encapsular a nova lógica:

- **`reference_sync.py`**: Contém o `ReferenceSyncManager`, um processo que roda em background e é responsável por ler periodicamente as variáveis de referência do OPC, coletar os valores das features associadas e salvar um novo registro de `PredictionData` no banco de dados. Este módulo é o coração do treinamento automatizado.

- **`control_manager.py`**: Contém o `ControlManager`, responsável por toda a lógica de controle preditivo. Ele calcula as recomendações de ajuste, aplicando a lógica (direta/reversa) e o fator de relação configurados, e possui métodos para aplicar esses ajustes no OPC.

## 3. Guia de Uso das Novas Funcionalidades

### 3.1. Configurando o Treinamento Automatizado

Para habilitar o treinamento automático de um modelo, siga os passos:

1.  **Crie um `PredictionTarget`**: Defina o que você deseja prever (ex: "Peso Final").
2.  **Cadastre as Variáveis de Entrada (`read`)**: Adicione as variáveis OPC que servirão como features para o modelo (ex: "Temperatura", "Velocidade").
3.  **Cadastre a Variável de Referência (`reference`)**: Crie uma nova variável OPC, defina seu tipo como **`reference`** e associe-a ao `PredictionTarget` criado. Esta variável deve apontar para o sensor que mede o valor real do seu target (ex: `ns=2;s=Balanca.PesoMedido`).

Uma vez configurado, o `ReferenceSyncManager` começará a popular a tabela `PredictionData` automaticamente, coletando o valor da variável de referência como `measured_value` e os valores das variáveis de leitura como o JSON `opc_values`. Com dados sendo gerados continuamente, o modelo pode ser retreinado periodicamente para se adaptar às mudanças no processo.

1.  **Cadastre a Variável de Controle (`control`)**: Crie uma nova variável OPC e defina seu tipo como **`control`**. Associe-a ao mesmo `PredictionTarget` do passo anterior.
